## Projetos e contribuições

### [PostureCare](https://github.com/manuzinho7/PostureCare)

**Contexto:** plataforma de saúde digital para monitorização contínua da postura, com telemetria de sensores, ingestão de dados, análise clínica e dashboards para acompanhamento de pacientes, investigação e saúde operacional.

**Contribuição:** autoria do projeto e desenvolvimento da implementação inicial; criação da camada de análise e visualização, documentação, dashboards e infraestrutura local/containerizada.

**Tecnologias:** Python, GraphQL, Docker, Docker Compose, PostgreSQL, Redis, Prometheus e Grafana.

**Tipo de participação:** autoria, desenvolvimento, infraestrutura e documentação.

### [Shodrone](https://github.com/Departamento-de-Engenharia-Informatica/sem4pi-2024-2025-sem4pi_2024_2025_g34)

**Contexto:** sistema académico colaborativo para gerir espetáculos multimédia personalizados com drones, incluindo backoffice, propostas, simulador, aplicação de cliente e testes.

**Contribuição:** desenvolvimento de funcionalidades de propostas e autenticação, incluindo controllers, serviços, UI e validação de disponibilidade de drones; criação de testes JUnit/Mockito, documentação, diagramas e integração através de vários pull requests.

**Tecnologias:** Java 17, Maven, Spring Boot, Spring Security, JUnit, Mockito, H2 e ANTLR.

**Tipo de participação:** desenvolvimento, testes, documentação e colaboração.
